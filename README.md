# Anil Kumar — Personal Portfolio Website

A responsive personal portfolio made with **HTML5 and CSS3 only**, following the internship project guide. No JavaScript, framework, backend, or database is used.

## Files
- `index.html` — semantic page structure and portfolio content
- `style.css` — colours, typography, layout, card styling, responsive media queries
- `images/` — optional folder for your own images
- `screenshots/` — save your desktop and mobile screenshots here

## How to run
1. Extract the ZIP file.
2. Open the `portfolio-project` folder in Visual Studio Code.
3. Open `index.html` in Chrome or Edge (or use Live Server if installed).
4. Click the navigation links and test the page at desktop and mobile widths.

## Before submitting
- Check your contact details.
- Replace the LinkedIn link with your real profile URL.
- Verify all content is accurate and that you are comfortable sharing the contact information publicly.
- Take desktop and mobile screenshots and save them in `screenshots/`.
- If you publish the site, add its public URL to your submission.

## Customisation
Edit the text in `index.html`. Change the colour variables at the top of `style.css` to adjust the palette. The two project cards currently describe a portfolio project and the NGO navigation enhancement internship work.
